# Roadmap: iCRM

## Project goal
Заменить разрозненную переписку с клиентами (почта, Telegram, WhatsApp, звонки)
одной системой, где каждое обращение — Разговор с понятным статусом «за кем ход»,
а задачи, контакты, организации и их оборудование связаны вокруг него.

## Success metrics
- Все клиентские обращения JDG ведутся в iCRM, ни одно не теряется.
- По каждому открытому разговору видно, чей ход, без ручных статусов.

### Phase 1: Ядро записей — CURRENT
**Goal:** универсальные записи, наборы, поля, правила, формулы, итоги, связи, YAML-конфиг.
**Exit criteria:** конфиг с наборами Задача/Монтаж загружается, правила и каскад итогов работают, покрыто тестами.
